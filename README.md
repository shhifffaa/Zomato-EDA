# Zomato-EDA
Exploratory Data Analysis of Zomato restaurants dataset focusing on ratings, cost, and dining trends.


About: Analyzed Bangalore Zomato dataset with 148 restaurants to study ratings, cost distribution, and online orders.

Steps: Data cleaning → Converting rating to numeric → Distribution & comparisons.

Key Insights:

Online order restaurants generally have better ratings.

Average cost for two people: ~₹418

Buffet is the most common listed type.

Tech Stack: Python, Pandas, Matplotlib, Seaborn.
